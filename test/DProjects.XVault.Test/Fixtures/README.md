# Fixture provenance

The `compatibility.json`, `.jsonc`, `.yaml`, `.env`, and `.md` files were generated by the canonical `marcdp/xvault` Python implementation at commit
`39f760c` (version `0.0.45`). `generate.py` fixes synthetic salt and nonce bytes so regeneration is reproducible; the committed artifacts contain no
real credentials. The fixture password is `correct horse battery staple`.

The XML fixture uses ciphertext and metadata produced by the same canonical crypto-v1 implementation, placed into the XML envelope understood by
`DProjects.XVault`. Canonical XVault recognizes `.xml` in this revision but its `HandlerXml` has no parse/stringify implementation, so this artifact
does not claim end-to-end canonical XML writer provenance.
