# Database

This area will document the architecture of database contracts, reusable database behavior, and provider-specific adapters.

Future documentation should explain:

- Which database concepts belong in the shared abstractions?
- What behavior is generic, and what remains provider-specific?
- What contracts govern connections, commands, and readers?
- How are schema and metadata differences represented?
- How are provider capabilities and limitations exposed?
- How do reusable provider-contract tests verify consistent behavior?
