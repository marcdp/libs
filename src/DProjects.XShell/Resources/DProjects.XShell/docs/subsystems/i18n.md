# Internationalization

This document introduces XShell's language and formatting service.

## Status

Draft.

## Configuration

The service stores a default language, a language list, date/time options and named formats, and a strings collection. Initialization replaces the default configuration with the supplied object and freezes that top-level object.

## Text selection

`formatText` selects language-specific segments from an encoded string form using markers shaped as `i18n:<language>=`. This is separate from the template compiler's expression behavior.

## Date and time

`formatDateTime` supports an explicit UTC ISO representation and configured `Intl.DateTimeFormat` options or named formats.
