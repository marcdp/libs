# Rendering Engines

A configured render engine owns rendered output for a definition-based Component or Page. The loader owns the Component or Page contract,
properties, public API, controller, services, lifecycle, and coordination with the state engine.

## Responsibilities

A render engine is responsible for:

- creating rendered output;
- mounting rendered output;
- updating or rendering output;
- unmounting rendered output;
- emitting template commands through the provided handler bridge when needed.

It does not own component or Page lifecycle, controller creation, public API exposure, contracts, property or attribute semantics, services, or
navigation.

## Command bridge

A render engine can be given a callback such as:

```js
handler: (command, ...params) => {
    this.onCommand(command, ...params);
}
```

This callback is only a bridge for commands generated by rendered templates. It does not give the render engine ownership of the controller or
lifecycle. The loader receives the command and decides whether and how to dispatch it.
