# Internationalization

This document introduces XShell's language and formatting service.

## Configuration

The effective configuration provides the service settings under `xshell.i18n`:

- `xshell.i18n.lang` is the current/default application language.
- `xshell.i18n.langs` describes the available languages.
- `xshell.i18n.datetime` contains default `Intl.DateTimeFormat` options and named formats.
- `xshell.i18n.strings` contains application/UI translation dictionaries keyed by language id.

XShell initializes its single `i18n` service with this effective configuration before modules start. The effective configuration is authoritative
after initialization.

## Translation

`translate` looks up an application or UI label in `xshell.i18n.strings` for the configured `xshell.i18n.lang`. It returns the source label when the
language has no dictionary or the label has no translation.

## Text selection

`formatText` selects language-specific segments from an encoded multilingual domain value using markers shaped as `i18n:<language>=`. Unlike
`translate`, it does not look up application/UI labels in a translation dictionary. This is separate from the template compiler's expression behavior.

## Date and time

`formatDateTime` provides locale-aware date/time presentation. It supports an explicit UTC ISO representation and the `xshell.i18n.datetime` default
`Intl.DateTimeFormat` options or named formats.

## Public helpers and limits

`getDefaultLang()` returns the configured language. `getMainLangs()` returns IDs whose language entries set `main`.
`getLang(id)` returns an entry or null; `getLangLabel(id)` falls back to the id.
`formatText(value, lang)` returns the selected marker segment, decodes `&#124;` to a literal pipe, and returns an empty string if no segment matches.
`formatDateTime(value, "iso")` emits UTC ISO text; other formats use Intl with configured options.
Named/default options are assigned into the supplied options object and may overwrite same-name caller settings.
There is no language-switch mutation API; effective configuration is frozen. [Dialogs](dialogs.md) language selection does not change it.
